How the score works

Each store gets up to 100 points across these checks. Pass is full points, partial is half, fail is zero. Checks that need Business Profile manager access are listed separately and are not scored yet.

Needs Business Profile access to check

  • Business description filled (750 characters, mentions services and the offer)
  • Services list with prices
  • Google Post in the last 30 days
  • Q&A seeded and answered
  • Holiday hours set
  • Messaging on with welcome message
  • Booking or quote link set
  • Insights: calls, direction requests, website clicks

Source: Google Places API (what Google shows publicly for each listing) plus the scraped reviews for velocity and reply rate. Refresh: node scripts/gbp-pull.mjs in the competitor-map project.
